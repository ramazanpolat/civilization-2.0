# Fırat Talk Workspace (`talks/2026-10-30-firat/`) — Agent Instructions

This directory holds the accepted deliverables for the **30 October 2026 Fırat University** talk ("Medeniyet 2.0: Yapay Zekâyla Birlikte Yaşam").

## `living-docs` Rules Here

- **Root holds only the current accepted talk deliverables:**
  - `icerik.md` — current 18-slide narrative and speaker notes ("Cepten Medeniyete").
  - `slaytlar.html` — current self-contained HTML presentation.
  - `gorseller/` — image assets for the current presentation.
  - `afis/` — approved event poster (`medeniyet-2-0-firat-v3.*`) and its `design/` source files.
- **Drafts sit beside accepted files:** e.g. `icerik-draft.md`, `slaytlar-draft.html`.
- **`history/` is read-only:** All earlier choreographies (`koreografi-v1.md`, `koreografi-v3...`, `icerik-v4...`), earlier slide decks (`slaytlar-v1..v4`), earlier talk maps, and earlier posters (`afis-v0-v2/`) are retired in `history/` and must never be edited.
- **Shared KB (`../../kb/`):** The sentence bank, story bank, terms, journal, and transcripts live in `../../kb/`.
