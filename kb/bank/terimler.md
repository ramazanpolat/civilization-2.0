# Terimler: Medeniyet 2.0 söyleşisi

Konuşmacının isteği (T3): terminolojide anlaşmak için temel kavramlar. Tanımlar
öğrenciye göre sade; konuşmacının kendi ifadesi olanlar işaretli.

Son güncelleme: 2026-10-24

## İç içe halkalar

Slayt için önerilen görsel:

```
Yapay zekâ ⊃ makine öğrenmesi ⊃ derin öğrenme ⊃ üretken YZ ⊃ LLM
LLM + harness = ajan
AGI, ASI: bugün var olan ürünler değil, ufuktaki hedefler
```

AGI ve ASI'yi tek cümleyle geç: açılışta "Skynet, bilinç… bunlara girmeyeceğim" deniyor.
